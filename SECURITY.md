# Security

Please report vulnerabilities privately through GitHub: **Security → Report a vulnerability** on this repository. Do not open public issues for security problems.

Scope: the connector's local HTTP server (origin and host checks, pairing, token handling), file writes outside the chosen folder, and integrity of downloaded runtimes.

Out of scope: code that the learner runs themselves — the connector is not a sandbox and runs programs with the learner's own permissions.
